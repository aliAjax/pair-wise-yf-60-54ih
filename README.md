# 无障碍人工审计协作工作台

源提示词摘要：审计员记录问题、复现步骤、影响人群和严重程度，审核员判断重复或补充证据，开发人员提交修复，复测人员关闭或重新打开问题；所有核心流程可以用键盘完成，并正确管理焦点和错误提示。

## 技术栈

SolidStart、TypeScript、Park UI、Solid Router、TanStack Query、Solid Store、Modular Forms、Zod、Solid i18n primitives。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62025`

## 可用流程

- 创建审计问题，保存复现步骤、影响人群、证据和严重程度。
- 问题按待分诊、修复中、待复测、已关闭和重新打开流转。
- 将重复问题合并到主问题，保留来源关系和操作审计。
- 开发修复与复测结果分开记录，复测失败自动重新打开。
- 支持跳过导航、可见焦点、读屏提示、`N` 快捷键聚焦新建问题、`Ctrl+Enter` 提交。
- 数据保存在 localStorage，Park UI preset 与 Ark UI 可访问交互原语参与界面实现。

## 离线合并任务包

- 导出：任务包携带全部审计问题、操作时间线和批次归属（批次号 + 来源工作站/角色/操作人），以当前身份面板为来源。
- 导入：按问题指纹（标题 + 流程 + 复现步骤的规范化哈希）合并；本地人工记录（备注、修复/复测说明）始终保留，只补空白。
- 整包校验：逐条核对动作与来源角色权限、复测/关闭所需的证据，证据缺失或来源权限不符即整包拒绝，不部分写入。
- 冲突裁决：两端对同一问题处置不同时，以合并时间线里最新有效动作归属为准；被覆盖的旧动作不删除，只在时间线留冲突说明。
- 幂等：事件按 ID 去重、问题按指纹去重，重复导入或分片重试不会重复累计。
- 断点续接：导入可暂停、失败可重试；容量不足时自动减半批次续接，最小批次仍失败则标记失败待人工重试。批次记录持久化，重开后仍看得到批次来源、未完成入口和每条处置的归属。
- 界面提供示例任务包生成（正常合并 / 权限不符 / 证据缺失）与“模拟容量受限”开关，便于单浏览器演示完整流程。
